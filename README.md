# Basalam MCP Server 🛍️🌿

Model Context Protocol (MCP) server for **Basalam (باسلام)**, Iran's largest social marketplace for independent creators, homemade goods, and artisan crafts.

## Features
- 🔍 **Artisan Product Search**: Discover homemade, organic, regional, and craft goods with price filters.
- 🏪 **Vendor Profile & Trust Scoring**: Calculate vendor trustworthiness (0-100) based on real reviews, satisfaction rates, and catalog consistency.
- 🎯 **Deal & Value Appraisal**: Economic appraisal and consumer buying advice for artisan listings.
- 💬 **Customer Feedback**: Real reviews, ratings, and Q&A from verified purchasers.
- 🔐 **User Accounts**: Mobile SMS OTP verification and session token management.
- ⚡ **Global Cloudflare Edge Support**: Remote worker live at `https://basalam-mcp.alphanet-edge.workers.dev`.

## Installation & Local Usage
```bash
pip install -e C:\Users\Administrator\Desktop\basalam-mcp
basalam-mcp
```
